## 💜 About

**JasperDroid** is an Android-focused adaptation of JasperEngine, aiming to bring its engine architecture and capabilities to mobile devices.

Developed with assistance from **OpenCode**, this project explores native Android integration, mobile graphics and an optimized development workflow.
